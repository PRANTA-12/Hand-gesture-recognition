\# AI-Powered Hand Gesture Recognition \& Real-Time Visual Effects System





An AI-powered real-time hand gesture recognition system that uses computer vision, hand landmarks, gesture recognition, and machine learning to control cinematic visual effects.





\## 🚀 Features





\- Real-time hand detection

\- 21-point hand landmark tracking

\- Single-hand gesture recognition

\- Two-hand gesture recognition

\- Gesture stabilization

\- Landmark filtering and smoothing

\- AI-based gesture prediction

\- Real-time visual effects

\- Particle effects

\- Fireball

\- Lightning

\- Energy Shield

\- Laser

\- Portal

\- Rasengan

\- Kamehameha

\- Gravity Orb

\- Cinematic HUD

\- Camera shake and visual effects

⚙️ Installation

Clone the repository:

git clone https://github.com/PRANTA-12/Hand-gesture-recognition.git

cd Hand-gesture-recognition

Create a virtual environment:

python -m venv venv

Activate it on Windows:

venv\\Scripts\\activate

Install the required dependencies:

pip install -r requirements.txt

▶️ Run

Start the application with:

python main.py

Make sure your webcam is connected and available.
